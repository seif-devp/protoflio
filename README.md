# Seif Amr - Flutter Mobile Developer Portfolio

A modern, responsive, high-aesthetic single-page portfolio website for **Seif Amr**, a **Flutter Mobile Developer** based in Cairo, Egypt. Built with Vanilla HTML5, CSS3 (Custom Glassmorphic Design System), and JavaScript.

## 🌟 Highlights & Features

- **Theme Toggle**: Dark Mode (default) and Light Mode toggle with automatic local storage persistence.
- **Dynamic Typing Animation**: Interactive typing headline highlighting core specializations.
- **Categorized Technical Skills**: Filterable skill cards (Clean Architecture, BLoC/Cubit, Supabase, SQLite, REST APIs, AI & NLP).
- **Featured Projects Showcase**: Filterable grid displaying 6 real-world Flutter applications:
  1. **AI-Powered Recruitment Platform (Graduation Project)** (Embedding Models, Semantic Search, Cosine Similarity)
  2. **Dawaya – Healthcare Assistant & Medical Reminder** (Offline-First, Supabase, Floor ORM, SQLite)
  3. **Music Streaming App** (Cubit, Dio REST APIs, Response Caching)
  4. **Help Desk Ticketing System** (Role-Based Auth, Cloud DB)
  5. **Note-Based Location App** (Geolocator GPS, Offline Persistence)
  6. **Metro Guide App** (Transit GPS Navigation)
- **Education & Certifications**: Highlighted credentials including Beni Suef University B.Sc., DEPI Scholarship, CS50 Harvard, and Udemy.
- **Direct Resume Download**: Direct link to download `Seif_Amr_ATS.pdf`.
- **One-Click Clipboard Copying**: Instant email & phone number copying with toast notifications.
- **SEO & Schema.org JSON-LD**: Optimized meta tags and structured data for search engine ranking.

## 🛠️ Technology Stack

- **HTML5**: Semantic tags & JSON-LD metadata.
- **CSS3**: Custom CSS Variables, Glassmorphism, CSS Grid & Flexbox, Smooth Scroll, Responsive Breakpoints.
- **JavaScript (ES6+)**: Dynamic DOM manipulation, filtering logic, local storage, typing animation, clipboard API.
